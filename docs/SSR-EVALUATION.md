# SSR/SSG 评估

P0 保持 SPA，并通过页面级元数据、动态 sitemap、robots 和结构化数据改善收录。P1 根据真实索引数据决定是否迁移公开内容到 SSR/SSG。

## 评估指标

- 百度、必应和 Google 对帖子、路线、活动详情的收录率。
- 搜索引擎抓取到的标题、描述和结构化数据是否正确。
- 首屏内容在禁用 JavaScript 时是否可读。
- 迁移对现有登录态、评论、点赞和活动报名的影响。

## 推荐路径

1. 先保留现有 React 应用，不整体迁移。
2. 将首页、路线、装备、活动、论坛和详情页拆为可预渲染的公开路由。
3. 登录后页面继续保留 SPA 交互。
4. 预渲染数据通过构建期快照或服务端接口注入。
5. 只有在收录和分享预览仍不足时，才考虑完整 SSR。
